GitLab YAML → XLSX

Укажите ссылку на YAML-файл в GitLab и токен доступа — приложение скачает файл через API GitLab, разберёт его с сохранением всех уровней вложенности и вернёт таблицу Excel.

Персональный токен со scope read_api (или api). Для публичных проектов можно оставить пустым.
Поддерживаемые форматы ссылок https://gitlab.example.com/group/project/-/blob/main/path/file.yml https://gitlab.example.com/group/project/-/raw/main/path/file.yml https://gitlab.example.com/api/v4/projects/123/repository/files/path%2Ffile.yml/raw?ref=main
